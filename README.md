## 🛠️ Tecnologías Utilizadas
- **Frontend:** React + Vite, CSS, React Router.
- **Backend:** Node.js, Express, CORS.
- **Base de Datos:** MySQL 8.4 (Aiven).
- **Despliegue:** Vercel (Frontend) y Render (Backend).

## 💻 Instrucciones para Ejecución Local
1. Clonar el repositorio.
2. **Backend:** 
   - Entrar a la carpeta `backend`.
   - Ejecutar `npm install`.
   - Crear un archivo `.env` con las credenciales de la base de datos.
   - Ejecutar `npm run dev`.
3. **Frontend:**
   - Entrar a la carpeta `frontend`.
   - Ejecutar `npm install`.
   - Ejecutar `npm run dev`.

## 🗄️ Base de Datos
El script para crear las tablas (`estudiantes`, `actividades`, `progresos`) se encuentra en el archivo `schema.sql`.
